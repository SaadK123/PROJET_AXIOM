# PROJET_AXIOM

Small Java experiment exploring object modeling, value types, and a simple interpreter/command-line style system.

## Structure

Main code is under `app/src/`:

- `Main.java` – entry point
- `Interpretor.java` / `CommandLine.java` – command handling
- `Obj.java`, `ObjectContainer.java` – object model
- `Value.java`, `ValueInt.java`, `ValueFloat.java`, `ValueDouble.java`, `TypeValue.java` – typed values
- `Utilitary.java`, `InitatorModelClass.java`, `IComponent.java` – helpers and interfaces

## Tech

- Java
- Simple object-oriented design

## Status

Educational / experimental project.
